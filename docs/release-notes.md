# Lust v0.1.4-alpha

## Что добавлено

- единая главная с подключением, списком серверов и подписками;
- поиск, группы, избранное и сортировка серверов по имени или TCP endpoint latency;
- безопасный deep-link и clipboard импорт подписок с подтверждением;
- отображение трафика, лимита и срока подписки из `subscription-userinfo`;
- versioned backup через системный Android document picker;
- три понятных режима маршрутизации для Xray и sing-box: всё через VPN, обход LAN и собственные исключения доменов/IP;
- universal APK и отдельные APK для `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`;
- SHA-256 checksums для всех APK.

## Что изменено

- нижняя навигация сокращена до «Главная», «Журнал», «Настройки»;
- основной экран настроек упрощён до выбора маршрутизации; технические параметры доступны по кнопке «Расширенные настройки»;
- URL подписки больше не отображается на главной, чтобы не раскрывать access token;
- ABI-specific APK примерно на 65–68% меньше universal debug APK;
- обновлены README, changelog и правила публикации релизов.

## Безопасность

- внешняя ссылка не запускает автоматическую загрузку подписки;
- backup полностью валидируется перед заменой состояния и требует подтверждения;
- содержимое clipboard, backup и subscription URL не записывается в журнал.

## Проверка

Релиз публикуется только после unit/build/lint, Android API 34 smoke для Xray и sing-box, проверки disconnect/reconnect и отсутствия fatal logs.

> Alpha-сборка использует debug-подпись и предназначена для тестирования.
