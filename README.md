# TRENZYCH VPN

A fast, secure, and lightweight Android VPN client built with Kotlin and Jetpack Compose.

## Features

- VLESS
- VMess
- Trojan
- Shadowsocks
- Hysteria 2
- TUIC
- Subscription Support
- Server Latency Test
- Import / Export Backup
- Dark Theme
- Xray-core Powered

## Download

Download the latest APK from the Releases section.

## Requirements

- Android 8.0 or higher
